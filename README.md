# Anket dizini

Statik site (derleme gerekmez).

## Codespaces'te çalıştırma
1. Bu klasörü (`index.html`, `data.js`) reponuza koyun ve Codespace açın.
2. Terminalde: `python3 -m http.server 8000`
3. Açılan "Ports" bildirimindeki 8000 portunu tarayıcıda açın (görünürlük Public yapılırsa link paylaşılabilir).

Kalıcı yayın için: repo Settings > Pages > branch `main` / root.

## Anket ekleme
`data.js` içindeki `SURVEYS` dizisine yeni nesne ekleyin. Alanlar dosyanın başındaki yorumda açıklı.
